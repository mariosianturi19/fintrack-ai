# Fintrack AI — LOGO-R0

Status: **R0 direction selected — Baseline A — Refined Lockup**  
Track: logo concept and validation  
Design direction: **Quiet Signal — Refined**

LOGO-R0 adalah eksplorasi bentuk hitam-putih untuk menentukan arah logo, bukan
logo produksi final. Warna brand, optical correction final, favicon, ikon PWA,
dan aturan clear space baru dikunci setelah satu arah dipilih dan diuji pada
checkpoint berikutnya.

## Tiga arah

1. **Signal Frame F** — monogram `F` yang memakai open scan frame.
2. **Refined Ledger** — wordmark-led monogram dengan terminal terpotong presisi.
3. **Receipt Trace** — monogram `F` dengan jejak sobekan struk.

Keputusan owner adalah membawa **Signal Frame F dengan Refined Lockup** ke
LOGO-R1.
Arah ini paling khas untuk ikon aplikasi dan paling langsung menghubungkan
capture, review, dan tracking. `Refined Ledger` layak dipertahankan sebagai
referensi kedisiplinan wordmark. `Receipt Trace` paling naratif, tetapi juga
paling berisiko menjadi ilustratif.

## Artefak utama

- `LOGO_R0_CONCEPT_SHEET.svg` — concept sheet vektor.
- `LOGO_R0_CONCEPT_SHEET.png` — preview lokal.
- `concepts/` — mark, reverse mark, dan lockup untuk setiap arah.
- `small-size/` — pemeriksaan ukuran aktual 16, 24, 32, dan 48 px serta preview
  raster 8×.
- `review-notes/LOGO_R0_SELF_CRITIQUE.md` — kritik dan rekomendasi.
- `review-notes/verification-report.json` — hasil pemeriksaan mesin.
- `tooling/` — generator dan verifier yang dapat dijalankan ulang.

## Tipografi

Wordmark memakai **Space Grotesk 600** sesuai `DESIGN_SYSTEM.md`. Font disimpan
lokal agar preview tidak bergantung pada CDN:

- `assets/fonts/SpaceGrotesk-Variable.ttf`
- `assets/fonts/OFL.txt`

Font berasal dari repository resmi Google Fonts dan berlisensi SIL Open Font
License 1.1.

## Batas LOGO-R0

- Belum menerapkan Mineral Blue, Rice Paper, atau Midnight sebagai kombinasi
  logo final.
- Belum menetapkan grid produksi, clear space, minimum size final, atau file
  favicon/PWA.
- Belum mengklaim keunikan merek secara legal.
- Belum mengubah `DESIGN_SYSTEM.md`.
- LOGO-R1 hanya dimulai setelah pemilik project memilih satu arah.
